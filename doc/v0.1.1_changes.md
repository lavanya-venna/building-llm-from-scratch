## Honest boundaries

- **The training loop does not exist yet.** `train_model` still ends at the
  `# TODO` comment block (see `doc/v0.1.0_changes.md`'s "Honest boundaries"
  for the prior statement of this same gap) — nothing in this version
  changes that. `DecoderOnlyTransformer.forward` is confirmed (via
  `src/model/model.py`) to take only `idx: (B, T)` and return logits
  `(B, T, vocab_size)`, with no built-in loss computation, so the training
  loop must compute `F.cross_entropy` externally, as already sketched.
- **No checkpoint code, checkpoint directory, or config key for a
  checkpoint path exists yet.** `data/artifacts/` is already gitignored as
  a whole (confirmed via `.gitignore`: it ignores `data/raw/`,
  `data/processed/`, `data/splits/`, `data/artifacts/`, `data/visualize`
  as named subdirectories, not `data/` wholesale), so a new
  `data/artifacts/checkpoints/` directory would not need a new `.gitignore`
  entry — but a location outside those named subdirs (e.g. a top-level
  `checkpoints/`) would.
